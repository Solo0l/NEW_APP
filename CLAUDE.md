# ChromaEscape — Project Constitution

**This document has higher priority than every future prompt. Never violate these rules.**
Read it at the start of every session before proposing or building anything.

---

## THE GAME
The game is NOT about colors. NOT about combat. NOT about upgrades.
The game is about ONE emotional reversal: **the hunter becomes the hunted.**

## CORE FANTASY
I am being hunted. I escape. I draw. I trap. I survive.

## CORE VERB
**Escape → Draw → Trap.** No other core verbs may ever exist.

## GOLDEN RULE
If trapping the Mote is not amazing, nothing else matters.

## DESIGN RULES
- No mechanic exists unless it improves trapping.
- No feature exists unless it creates better trapping.
- No content exists unless it creates new trapping *situations*.

## FORBIDDEN (never suggest, never build)
Skill trees · RPG systems · currencies · crafting · loot · random upgrades ·
talent systems · quest systems · dialogue systems · story systems · collectibles ·
power progression · new core verbs.

## PROGRESSION
The player becomes more **SKILLFUL**, never more **POWERFUL**.

## CONTENT
Future content may ONLY change: Arena · Enemy behaviour · Timing · Pressure ·
Geometry · Patterns · Psychology. **Never the core mechanic.**

## THE ONE TEST (apply to every future idea)
Does this make **Escape → Draw → Trap** better?
If it weakens or distracts from the core — **delete it**, even if it is my own idea.

---

## CURRENT STATE (context for future sessions)
- **Frozen foundation:** `ChromaEscape_Prototype_0.6.html` ("The Trap"). The single mechanic:
  move → leave a fading lasso → close a loop around the mote to catch it. Catching is the
  only score, the only heal, and the only relief. Each catch, the mote returns faster.
- Prior prototypes 0.1–0.5 are earlier explorations; 0.6 is the baseline everything builds on.
- Feel already in 0.6: ~90ms hit-stop + shake + spark burst + rising trap-tone on catch;
  the mote has a watching eye; audio is silence-based with a proximity heartbeat.
- **The open question that outranks all roadmap work:** does the *first successful trap*
  feel amazing in a real player's hands? Per the Golden Rule, confirm that before building
  anything else. Roadmap situations (dash-tell, walls/closing space, second mote, mortal
  stakes) exist only to create NEW TRAPPING SITUATIONS — never to add systems.
